# Tarefa: resumir o processo

Produza um resumo estruturado do processo, a partir SOMENTE dos dados do contexto.

Inclua, nesta ordem: partes, ação e valor, resumo dos fatos, fase atual, prazos em aberto e pontos de atenção
(prazos curtos, documentos que parecem faltar, riscos evidentes).

- Cada afirmação deve poder ser conferida nos dados fornecidos. O que não estiver nos dados, não entra.
- Se o contexto for insuficiente, pergunte qual processo ou quais dados usar.
- Devolva uma única sugestão do tipo "Resumo".
- Se o PEDIDO DO ADVOGADO trouxer instruções específicas (tema, tom, tamanho, foco), siga-as.
